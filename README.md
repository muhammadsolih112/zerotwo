# zerotwo

Darling in the Franxx — Zero Two va Hiro uchun React fan-sayti.

## Ishga tushirish

```bash
npm install
npm run dev
```

Production: `npm run build`. Tayyor fayllar `dist` papkasida yaratiladi.

## Netlify

Ushbu GitHub repozitoriyni ulang. Build command: `npm run build`. Publish directory: `dist`. Node.js: 22. Sozlamalar `netlify.toml` ichida.
